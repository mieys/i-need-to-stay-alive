Başlangıç statları ayarı

Yüzde stat yok. Saldırı Hızı bonusu oyundan kaldırıldı (eski değeri "Şimdi" sütununda bilgi için duruyor). Seçili satırlara yeni değer uygulanır, seçili olmayan karakter şimdiki değerlerinde kalır. Değerleri düzenle, en alttaki metni kopyalayıp bana yapıştır.

Puan ölçütü: 1 puan = Taban:
Karakter Şimdi
Can/Hız/SG/AtkHızı%		 CanHızSG PuanRol / not

Puan = (Can−taban)/ölçüt + (Hız−taban)/ölçüt + (SG−taban)/ölçüt. Yeşil 0 = bütçede, turuncu = üstünde, kırmızı = altında. Vampir'in pasifi (1 SG = 1 can) puana dahil değildir; onun −1'i bilinçli. Turuncu çerçeve = şimdikinden farklı değer.
